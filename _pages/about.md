# Zehao Wang

**Third-year Ph.D. Student in Software Engineering, Tianjin University**

I study **reliable and self-improving LLM agents and multi-agent systems**. My research focuses on how agents can **make reliable decisions, coordinate effectively, diagnose failures, and continuously improve from interaction and experience**.

# Research

My research is organized around a central question:

> **How can LLM agents become more reliable and continuously improve from their own experience?**

### Reliable LLM Agents

I study agent reliability from a **decision-centric and epistemic perspective**, focusing on whether agents possess and appropriately use the knowledge required for reliable decisions.

- Epistemic calibration
- Decision reliability
- Reliable planning and execution
- Failure diagnosis and attribution
- Causal-inspired reasoning
- Hierarchical decision intervention

### Self-Improving Agents

I investigate how agents can **learn from interaction, experience, and failures** rather than relying solely on static prompts or external supervision.

- Agent reinforcement learning
- Long-horizon trajectories
- Credit assignment
- Online knowledge evolution
- Self-improving agents
- Self-evolving agent systems

### Trustworthy AI

I work on trustworthy AI and intelligent risk-control systems, where **behavioral modeling, reasoning, and anomaly detection** intersect.

- Risk reasoning and intervention
- LLM safety and robustness
- User behavior modeling
- Graph and temporal anomaly detection
- Illicit-account detection

# 研究方向

我的研究围绕一个核心问题展开：

> **如何让 LLM Agent 做出更加可靠的决策，并能够从自身经验中持续学习和改进？**

### 可靠的 LLM Agent

从**决策中心（decision-centric）和认知知识（epistemic）视角**研究智能体可靠性，关注智能体是否拥有并正确使用完成可靠决策所需的知识。

- 认知校准
- 决策可靠性
- 可靠规划与执行
- 失败诊断与归因
- 因果启发式推理
- 分层决策干预

### 自我改进型 Agent

研究智能体如何从**交互、经验与失败中学习**，而不是仅依赖静态 Prompt 或外部监督。

- Agent 强化学习
- 长程轨迹学习
- Credit Assignment
- Online Knowledge Evolution
- Self-improving Agents
- Self-evolving Agent Systems

### 可信人工智能

研究可信 AI 与智能风险控制系统，关注**行为建模、智能推理与异常检测**之间的结合。

- 风险推理与干预
- LLM 安全与鲁棒性
- 用户行为建模
- 图与时序异常检测
- 黑产账号检测

# 研究项目

### 可靠多智能体系统

通过**认知校准、失败归因、分层干预和结构化推理**提升 LLM 多智能体系统的可靠性。

### 自演化智能体系统

探索**在线知识演化与 Agent 强化学习**，使智能体能够从交互中学习有价值的决策知识，并持续改进自身行为。

### AI 风险控制

将**LLM 推理、行为建模、图学习与异常检测**应用于真实场景中的智能风险识别与干预。
